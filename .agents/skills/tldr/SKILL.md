# TL;DR

把輸入壓到最短、還能讓人抓到核心。要的是骨架，不是詳細摘要。

## 原則

- **只留核心。** 保留「漏掉就抓不到重點」的那幾點，其餘一律砍——背景、鋪陳、次要細節、過程都不留。
- **壓到最短。** 預設 3 條以內，每條一句話；能用一句話講完整件事就別分條。
- **依內容決定「核心是什麼」。** 概念或文章 → 核心主張與結論；討論 → 結論與待辦；程式碼 → 真正改變行為或決策的地方。輸入是什麼型態自行判斷，不需使用者指定。
- **用輸入的語言。** 預設繁體中文。

## 輸出

- 至多 3 條 bullet，每條一句。需要時可在最前面加一句總結。
- 純重點，不解釋推導過程、不補背景。

太長就是沒做到——回頭再砍。
