# HTML 呈現元素

產出閱讀用 HTML 時的呈現規則，只講版面與互動，與內容取向無關，任何產 HTML 的 skill 都可以引用。這裡給的是元素與行為，不是樣板：配色、字體、明暗模式、版面風格都自由發揮。

## 基本規則

每份 HTML 都套用：

- **單一自含**：CSS、JS 都 inline，雙擊檔案就能完整閱讀。外部函式庫只在[圖](#圖)的例外情況使用。
- **語意化 HTML**：`<header>`、`<nav>`、`<main>`、`<section>`、`<table>` 等各司其職，標題層級連續。
- **跳轉瞬間到位**：保持瀏覽器預設的 `scroll-behavior: auto`，JS 也用瞬間跳轉。
- **頁內跳轉用 `<a href="#id">`**：讓每次跳轉都進瀏覽紀錄，讀者按上一頁（Cmd+[）就回到原處。
- **標題可連結**：每個 `h2`、`h3` 帶穩定的 `id`；滑鼠移上去顯示 `#`，點擊更新網址，方便複製該段連結。
- **目標不被遮住**：有 sticky 的頂部元素時，所有錨點目標設 `scroll-margin-top`，值不小於該元素高度。
- **好讀的欄寬**：內文欄寬約 70–80ch；表格、圖可以比內文寬。
- **窄螢幕可讀**：頁面本身不出現橫向捲動，過寬的表格或圖在自己的容器內捲動。

## 元素選用表

逐一判斷，條件成立才用。

| 元素 | 何時用 | 何時別用 |
| --- | --- | --- |
| [TOC](#toc) | 約 4 個以上的大章節 | 短文件，標題本身就看得完 |
| TL;DR | 讀者只想先知道結論，例如討論總結、調查結果 | 內容本身就是一段短結論 |
| [詞彙表](#詞彙表與來源清單) | 專有名詞或自訂定義在文中被重複提到 | 名詞只出現一次，就地解釋即可 |
| [來源清單](#詞彙表與來源清單) | 多個來源，讀者需要追溯某段話出自哪裡 | 單一來源，放在頁首一行交代即可 |
| [複製路徑](#複製路徑) | 提到本地檔案或程式碼位置 | — |
| [圖](#圖) | 3 個以上節點，有分支、循環或多對多關係，文字講不清 | 單純線性步驟，用編號清單 |
| [手風琴](#手風琴) | 細節只有部分讀者需要，攤開會打斷主線 | 主線必讀的內容 |
| [互動表格](#互動表格) | 見該節的門檻 | 未達門檻，用靜態表格 |
| [Tabs](#tabs) | 同一件事的平行視角，讀者一次只看一個（before／after、多語言寫法） | 讀者需要全部看完或並排比較的內容 |
| 對照版面 | 兩個以上方案、版本要並排比較；diff | 只有一方，或差異一句話說得完 |
| Callout | 需要跳出主文的提醒：注意事項、風險、提示、agent 補充 | 一般段落；滿頁 callout 等於沒有重點 |
| Badge | 有狀態、類型、優先度這類可快速掃讀的標籤 | 標籤只出現一兩次 |
| 時間軸 | 內容依時間或版本先後展開 | 沒有時間順序的內容 |
| [程式碼複製鈕](#程式碼複製鈕) | 讀者可能直接貼上的指令或程式碼 | 只用來說明、不會被執行的片段 |
| [動畫](#動畫) | 傳達狀態變化或先後順序 | 純裝飾 |

## 元素規格

選用表沒有連到這裡的元素，行為自由發揮。

### TOC

- 寬螢幕放側欄並 sticky；窄螢幕收合成可展開的選單。
- 用 IntersectionObserver 標示目前讀到的章節（scrollspy）。

### 詞彙表與來源清單

兩者都是「定義一次、各處引用」：定義集中在一個 section，內文用 `<a href="#id">` 連過去，不做反向連結。

- **詞彙**：以詞彙本身當連結文字，`title` 放一句定義摘要，滑鼠移上去就能預覽。
- **來源**：內文用 `[1]` 這類標號連到文末來源清單。清單裡的本地檔案用[複製路徑](#複製路徑)，URL 用一般連結，對話內容寫「本次對話」。

### 複製路徑

- 顯示並複製 **repo 相對路徑**，知道行號時接 `:行號`（如 `src/auth/login.ts:42`），讓讀者貼進 IDE 的快速開啟直接跳到該行。不在 repo 裡的檔案用絕對路徑。
- 外觀醒目且跟一般連結有區別：等寬字體加複製圖示。
- 點擊後就地顯示「已複製」，約 1 秒後消失。`navigator.clipboard` 不可用時，退回 `document.execCommand('copy')`。
- 外部 URL 用一般連結，開在新分頁。

### 圖

- 預設用 inline SVG 或 HTML/CSS 畫。
- 節點多到需要自動排版、手畫成本明顯過高時，才改用函式庫（如 Mermaid），從 CDN 載入，URL 寫死確切版本號。

### 手風琴

- 頁面有多個手風琴時，提供「全部展開／全部收合」按鈕。

### 互動表格

這是成本最重的元素，符合以下任一條件才加互動：

- 約 15 列以上。
- 讀者需要依某個欄位找出特定一列，或比較大小。

行為：

- **搜尋**：一個搜尋框，比對所有欄位；按 `/` 聚焦搜尋框（焦點在輸入框內時不攔截）。
- **過濾**：只用在有明確類別的欄位（狀態、類型），選項從資料中取得。
- **排序**：點欄位標題切換排序，目前的排序欄與方向看得出來；數字、日期依值排序。
- 顯示目前筆數與總筆數，例如「12 / 40」。

### Tabs

- 預設選中最常用的那個視角。

### 程式碼複製鈕

- 放在程式碼區塊角落，點擊後的回饋方式與[複製路徑](#複製路徑)相同。

### 動畫

- 只用來傳達狀態變化或先後順序，例如展開收合的過渡、流程圖逐步亮起、過濾後的列表重排。
- 時間約 200ms 以內。
- `prefers-reduced-motion: reduce` 時關閉動畫。
