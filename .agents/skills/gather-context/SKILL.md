# 蒐集 Context 與盤問

正式規劃（create-plan）之前的第一步：把 user 一句話的意圖與零散來源，收斂成一份乾淨、
無歧義、可直接餵給規劃的開發依據。核心手段是**盤問**——把每個會影響開發的模糊點、缺口與
矛盾挑出來，逼 user 給出明確答案。盤問怎麼進行，一律依 [`grilling`](../grilling/SKILL.md)
skill；本文件只負責兩件事：在開發情境下**要盤問哪些缺口**，以及把結果**整理成哪些檔案**。

## 核心原則

1. **不自行假設。** 模糊、缺漏、矛盾只要會影響開發決策，就列成問題交給盤問；沒得到回答
   之前維持待答，不用猜測補上，也不進到定稿。
2. **context 是萃取，不是照抄。** 從 Figma／PRD／程式碼／對話裡挑出「會直接影響怎麼做」的
   內容寫進 context.md，其餘略過；不是把來源整份搬進來。
3. **有根據才寫。** 每個結論都對得上某個來源或 user 的回答；找不到根據就變成一題問題。
4. **對程式碼與來源唯讀。** 只讀不改；唯一允許的寫入是任務資料夾底下三個產出檔。

## 流程

### 1. 吸收來源

讀 user 的意圖，以及 user 指定的每一個來源（現有程式碼、Figma、PRD、先前對話）。
**完成判準**：能用自己的話講清楚「這次要做什麼、範圍到哪、會碰到哪些現有的程式碼與設計」。
講不清楚的地方，就是下一步的問題來源。

### 2. 盤點缺口，列出盤問題目

拿「要做的事」對照來源，逐一檢查下列每一類缺口，整理成盤問的題目（即 grilling 起始的
問題來源）。**完成判準**：每一類都檢查過，凡是會左右開發決策的模糊點都已成為待盤問的
題目，沒有遺漏。

- **範圍邊界**：要做什麼、明確不做什麼（非目標）。
- **模糊詞彙**：同一個詞在不同來源／不同人口中是否指不同東西。
- **隱藏假設**：整個做法默默建立在上面、卻沒被講出來的前提。
- **邏輯矛盾**：來源彼此打架，或 user 前後說法不一致。
- **邊界情境與錯誤處理**：極端輸入、失敗路徑、空狀態。
- **相依與整合點**：會動到哪些現有模組、外部系統、資料流。
- **驗收標準**：怎樣算做完、做對。
- **決策取捨**：有多個可行作法時選哪個、理由是什麼。

### 3. 盤問 user

依 [`grilling`](../grilling/SKILL.md) 進行：把第 2 步的缺口當成起始問題，交給 grilling
分輪盤問，直到它的 frontier 清空。盤問的節奏、提問格式與追問方式都以 grilling 為準，
這裡不重述。**完成判準**：每個缺口都被問過並得到 user 明確回答，沒有任何一題空著或由你
代答。

### 4. 定稿三份檔案

用盤問得到的答案回填，產出／更新任務資料夾底下三份檔（見「輸出」）。
**完成判準**：三份檔內部一致——context.md 不與任何已確認的答案矛盾，term.md 涵蓋 context
與問答裡出現的專有詞彙。

### 5. 回報

摘要：整理出的核心 context、問了幾題、有無仍待 user 確認的地方。

## 輸出

每個任務一個資料夾 `.plan/<slug>/`（不存在就建立）。`<slug>` 用 kebab 描述這次的
feature／bug，例如 `feature-auth-module`（沿用 create-plan 的命名；若已有同一任務的資料夾
就用它）。同一個 worktree 可並存多個任務資料夾。三份檔都放進這個資料夾。

### `.plan/<slug>/context.md`

這次開發的完整依據，只放「會直接影響怎麼做」的內容。建議章節：

- **目標**：一句話講清楚要達成什麼。
- **範圍與非目標**：要做的、明確不做的。
- **來源重點**：從 Figma／PRD／現有程式碼萃取、影響開發的關鍵點。

### `.plan/<slug>/question.md`

盤問的完整紀錄，每題一段：

```md
## Q1: <問題>
- 背景：為什麼問（對應哪個缺口／矛盾）
- 回答：<user 的完整回答>
```

### `.plan/<slug>/term.md`

共用專有詞彙表，讓後續討論精準對齊。每筆一行：

```md
- **<術語>**：定義；必要時註明它在本專案的特定用法，或與一般用法的差異。
```

## 限制

- 對程式碼與來源唯讀：不改 source、不跑會改動狀態的指令；唯一寫入是任務資料夾下三份檔。
- 未獲回答的問題維持在 question.md 待答，不自行定案。
- context.md 只收影響開發的內容，不做來源全文轉貼。
